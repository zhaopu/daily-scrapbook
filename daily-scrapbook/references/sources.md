## 版式白模

`layout-overview.png` 是原创抽象结构图。每页用六个白色占位符演示照片、人物抠图、物件抠图与批注的关系；它不是成图质量示例，也不是固定坐标模板。

| 标签 | 结构 |
|---|---|
| A | 情绪主图＋片段浮贴 |
| B | 日常碎片拼贴 |
| C | 周末小报 |
| D | 小型时间轴 |
| E | 主题中心＋周边细节 |
| F | 主角抠图＋照片卡，E的常用变体 |

真实照片与主体轮廓会改变排布。全图保留优先；白模不能成为删图、生成假图或整齐套版的理由。
