# 成图检查与修复顺序

## 硬性检查

查看实际输出并对照用户原图：

- [ ] 默认所有来源照片都出现，P1—Pn逐一核对；任何省略有事前告知与用户明确取舍；同图抠图没被误当新增来源。
- [ ] 页数与要求一致；多页制作前已告知页数、分配和理由，不把用户的一页要求直接改成多页。
- [ ] 人物、服装、动作、宠物、物件与来源一致，无新人物、新事件或五官混合。
- [ ] 文案能追溯到用户或可见画面；没有猜日期、地点、关系、台词和感受。
- [ ] 中文逐项正确，无伪字、随机英文、裁断句尾，手机观看可读。
- [ ] 比例符合要求，不拉伸照片；脸、手与叙事重点未被裁掉/遮住。
- [ ] 一张完整单页，无故增加的桌面/本子外景不存在；不是多页缩略拼图。

硬性失败先修复，不能以整体好看代替。未做原图图层合成时，不使用“像素不变”“无损拼贴”等表述。

## 审美检查

缩到约 360—430 像素宽看整体，再放大看字：

- 第一眼有主图或明确图组，视线自然经过主要照片。
- 每段字靠近所指对象，读者不用寻找对应关系。
- 有一两块连续的干净纸面，缩到手机宽度仍能看到停顿；纸面上不再叠文字、贴纸、箭头或色块，不把照片白边当作留白。留白帮助分组，照片没有被挤成小缩略图，也没有生硬的大块空白或空页脚。
- 装饰呼应内容，纸纹不影响细节；花字、贴纸和线条带来变化，背景既有巧思也有连续留白，不极简成统一黑字配白框。
- 颜色来自照片，仍有真实生活气息。
- 图文有节奏，避免用户已否定的统一四格套框；明确要求四格时按其选择判断。
- 默认有自由拼贴感：大小、局部倾角、偏移和间距有变化，允许安全的跨边缘或叠放；不是整齐卡片列表、等距网格或整页同方向旋转。照片全覆盖、主体无遮挡、阅读顺序清楚。
- 保留用户语气，不统一写成“普通一天也值得记录”等通用句。

## 最小修复

| 问题 | 动作 |
|---|---|
| 人物/服装变化 | 重新附来源原照局部修；仍不稳则说明，不宣称无损 |
| 漏图 | 补指定 P 编号与位置，不重新随机选图 |
| 编造信息 | 删除无依据标注，用已确认或中性短句 |
| 错字 | 成图局部替换，逐条给正确文本 |
| 字太多 | 缩文案或拆页，不缩到不可读 |
| 太规整 | 打破齐头齐尾与等间距，局部换大小、角度与偏移，加入一处安全叠放/跨边缘，批注利用空隙；不要只旋转整齐网格 |
| 太满/没有留白 | 先删重复贴纸、星点和多余连线，必要时收小标题；在标题旁、图组之间或人物轮廓外侧腾出一两块连续纸面，保留所有来源与照片可读尺寸 |
| 太乱 | 按事件分组，删重复装饰，减跨组重叠 |
| 遮脸 | 移批注/贴纸，不替换原照 |
| 太旧/太暗 | 纸面减噪提亮，保留照片颜色 |
| 串入作者人物/文字 | 删除外来内容，重新明确 USER CONTENT / STYLE ONLY |

最多两轮有明确目标的修复。偏好更新先作为当前任务约束，只有用户要求时才持久改技能。
