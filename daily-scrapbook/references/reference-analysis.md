# 参考 A—F：元素拆解与差异校准

依据：用户于 2026-10-23 提供的六联参考图与局部放大图。以下区分可见元素、关系判断与执行建议；比例和字号关系是视觉估计，非原稿测量。缩略图小字不可靠，不转录其具体事件、姓名和日期。参考图仅用于分析，不作为用户素材或公开再分发资产。

## R-A：中心人物与年度节点

**构图**：较大内层布纸承载整页，左侧有不规则撕开边；人物全身抠图位于中间，外围月份笔记松散环绕。人物本身是视觉锚点，标题年份较小，不设巨大标题栏。月份按年度组织，但没有一根必须贯穿全页的粗时间线。

**照片与材质**：主角是无矩形背景的完整人物轮廓，细节照片很少、很小，有圆形小图。布纹和左侧破边在这张承担材质表达，不应推广为所有页必须撕边。

**字形**：年份、月份名、正文三层，黑色自然手写。月份标题略大，正文分行，围绕身体避让；各块文字行数和宽度不同。

**辅助元素**：彩色小图标与月份事件邻近，搭少量心形、星点、箭头。彩色点缀尺寸远小于人物，月度节点分散但不等角度环形均分。

**适用条件**：年度回顾、成长节点。没有已确认月份内容时，不能补满十二个月；没有完整人物照时不能补画全身。

## R-B：图组底板与表情穿插

**构图**：三块棕色图组底板分段，第一块与右上标题形成互补，后两块横向延展。人物半身/表情抠图探出底板，在块与块之间形成节奏。

**照片与边界**：每块底板里包含多张照片，强调的是“一组经历”的边界。棕板外围有细黑、略有手绘感的轮廓；内部照片不每张套同款粗白框。人物抠图数量和尺寸服从表达，不强制一页只能一个。

**字形**：粗棕手绘标题承担较强识别，图组下说明和顶部小段落较细较小，气泡内语句另有层次。不能把这张误读成全页细黑字，也不能把粗标题和棕底板复制到 R-E。

**辅助元素**：有指向人物的气泡、短放射笔画、星芒和小物件。气泡的尾巴/邻近关系给出归属，而不是任意空隙放一个装饰气泡。

**适用条件**：活动合集、主题攻略、可分组的多图。依据来源分组，不为复刻三块棕板编出三类经历。

## R-C：小报与编辑层级

**构图**：暖底纸上嵌一张白色内页。顶部有独立报头带、黑色刊名字形、细英文/小字信息、色点和水平线。中部活动照片小组与文字并置，下部转为餐食照片与局部抠图，中间斜线形成分段。

**照片与边界**：矩形活动照片、小人物抠图、整张餐食照、沿碗盘轮廓抠出的食物并存，形状差异有明确用途。内部有适度对齐和列关系，小报结构不需要为了“自由”破坏。

**字形**：报头、正文、短手写强调、竖排旁注、少量既有编辑信息属于不同角色；手写与印刷感字形可以共存。变化来自编辑角色，不是每句话随机换字体。

**辅助元素**：线条负责分区，手绘指示和小强调词贴近对象。不是靠一圈图案制造杂志感。刊名、期号、日期、署名只在用户提供或同意原创命名时使用，不能复制参考原刊名与身份。

**适用条件**：两个或更多有清晰区分的内容组。正文较多时先压缩，不生成不可读假字填栏。

## R-D：日常碎片与真实小物

**构图**：无统一顶栏，多张不同长宽比照片上下错落。局部棕色圆角底板把室内、人物圆图和小字收成一组，周围还有食物与动作场景。

**照片与边界**：无框/薄边矩形照片、局部圆形人物、真实物件抠图、分组底板各占一部分，不能把每张都做成相纸卡。部分照片边缘彼此靠近或相叠，阅读仍有落点。

**字形**：较大的 plog 描边字、主照片旁的图注、白色小纸条局部字、小段细手写、音符等混合。标题装饰只在一角，不把所有说明做成花字。

**辅助元素**：食物/物件照片抠图带一点边，结合小音符、短线和内容相关图案。实拍物件与手画符号的质感不同，这种材料差异本身就是层次。

**适用条件**：做饭、周末、家居生活等碎片。优先从用户照片提取小物，不额外添加不存在的餐食和道具。

## R-E：细手写、轻相纸、下部主图

**构图**：上部两张较小相纸与标题相互避让；第三张集体活动照位于中间偏下，跨接上部底纸和下方大图。下半部完整照片大幅铺开，不套与小图相同的相框。过渡照片使上下有穿插，而非整齐分两层。

**照片与边界**：小图具有平直、略旧的薄相纸边，主照片没有同款白框。倾角轻微，照片形状/裁切与摆位有差别。关键是小照片、过渡图、主图三种角色，不是五张一样的相框换角度。

**字形**：
- 标题是松散细黑手写，可在两张照片之间折行，未占据整条页眉。
- 相纸下沿一句主要图注较大，独立可读。
- 相纸旁和主图旁的小段补充字明显更小，行数与宽度随空隙改变。
- 气泡中的短旁白另成一个小语气单元，字体并不比每张图注都大。
- 一页内可保持同一支笔的感觉，用字号、行距、字距、粗细和位置变化，不必混用五六种字体。

**辅助元素**：
- 标题旁小书包为微型线描，连接主题与两图空隙，细节简化，不承担视觉主角。
- 左侧星芒邻近一小段字，为句子起点或情绪强调；不是照片四周都加星星。
- 很小的心形是另一个语气点，没有平均分布。
- 右下云状气泡贴着主照片安静区域，细线、轻填色或透出背景；轮廓不规则，尾巴/位置与对象有关。不能只把文字塞进大白云贴纸。

**适用条件**：幼儿园日常、某次活动、情绪清楚的主照片。四五张输入也必须全保留，可把额外照片做窄场景、小细节或图组，不能为凑参考的四张而省略。

## R-F：红色时间轴与节点卡

**构图**：粗红路径串起左右节点，每块圆润红色底板包含缩略图、日期、简短说明；沿时间向下阅读。底板与路径是信息结构，不是零散背景装饰。

**照片与边界**：多是不同日期的成果或记录缩略图，图小也有用途，因为是回顾索引；不能把日常主照片也全部缩成这种大小。

**字形**：大红描边标题、较大的日期数字、白色手写正文构成强反差，日期是可扫描锚点。标题可以比 R-E 粗大，但仍与整页红色路径一致。

**辅助元素**：短弯箭头、局部心形、小抠图点在节点之间。红色先统一信息流，其余颜色从照片来，不能同时加入 R-B 棕底板与 R-E 同款大图。

**适用条件**：用户确认日期的月份回顾、作品合集。日期未知时改主题索引或其他版式，不编时间。

## 元素的职责：选择而非拼满

| 元素 | 在参考中的职责 | 生成时容易偏离的地方 |
|---|---|---|
| 页底与内层纸 | 统一背景，或分出整张内页 | 所有页都套厚颗粒、破纸和强阴影 |
| 原照片 | 提供生活内容和视觉主次 | 用近似场景反复重绘替代来源 |
| 薄相纸边 | 给少数图可拿起的感觉 | 每张粗框、每张撕边 |
| 无框主图 | 让照片成为整页的一部分 | 主图也缩进同款卡片，像照片墙 |
| 人物/物件抠图 | 跨图组、强调表情或局部 | 到处粗白描边，所有照片都抠人 |
| 标题 | 为该页定语气和入口 | 自动变成占满页宽的海报标题 |
| 主图注与小旁白 | 区分“看图说明”和“补充语气” | 每图一句等长、同字号、同位置 |
| 微型贴纸/线描 | 在局部连接字与图 | 只增加数量、放大到与照片竞争 |
| 星芒/心形/短线 | 提示句子起点或情绪 | 给每个图注都配同一划线与放射线 |
| 气泡 | 给一段字范围与归属 | 大白云统一套框，编造人物对白 |
| 底板/分隔线/路径 | 组织图组、栏目、节点 | 把所有页都改成一张一框或强制散贴 |

## 与“看小松鼠”v4 的具体差异

这是对已生成版本的判断，不是对原参考的精确测量。

1. **骨架仍像照片墙**：上面四张辅助照片接近两列等权重，下面一张大照片；参考 R-E 的中间过渡照跨接上下，文字也参与构图。加贴纸没有改变这层结构。
2. **标题占比仍高**：v4 的标题整块偏大，R-E 的标题更像夹在图间的两三行笔记。需要移动并收小标题区域，而非仅换成黑色。
3. **图注尺寸和长度仍接近**：已有大小差，但主要仍是一张图配一句大图注；可将主要短句、次级旁注、气泡文字分级，并允许一段说明关联一个图组。主文字保持清楚，补充小字不承担关键信息。
4. **边框过于统一**：v4 五张基本都套相似相纸边，R-E 主图与浮贴图处理不同。A 模式下大图可直接落在页底，小照片保留薄边。
5. **装饰尺度偏大、过于完整**：帽子、风车和气泡画得较完整，容易变图标展示；参考的小画更简练，笔画不必把物体结构交代完整。
6. **点缀重复**：v4 出现多处黄色划线/放射笔画，重复形成“每张都被设计”的感觉；参考存在无装饰的照片和纯文字区域。
7. **气泡显眼程度偏高**：v4 下方大浅色云和较大的字成为独立标签；R-E 的云靠近照片场景、线轻、字小、形更扁，和画面融合。
8. **五张横向近景素材的限制**：用户这组照片长宽比相同，且四张涉及相近庭院。自然缺少参考的远近/照片比例差异。可在不裁关键人物动作的条件下改变裁切与层级，保留所有来源；不能假装照片本身已有强烈差异，或为改善多样性制造新场景。

## 写入页面计划的最小设计选择

每次先选一条视觉组织，再选辅助元素。不要写“参考全部优点、字体丰富、贴纸多一点”这样的混合要求。

- 视觉组织：选 R-A—R-F 中哪一条关系，或用户另给的参照；记录与技能库名称的对应。
- 照片角色：主图、次图、过渡图、细节图、图组成员；不必各角色都有，但不能所有来源等权。
- 字体角色：标题、主图注、补充字、日期/栏目，分别写相对大小、粗细与摆位；只出现有用角色。
- 材料差别：哪几张薄边、哪张无框、哪处抠图或分组底板，给出实际选择。
- 辅助元素：选两三种以内的线描/星芒/气泡/物件，写清服务哪个图组/文字；也明确哪些图不装饰。
- 疏密：标出连续安静纸面与跨接位置，装饰不回填所有缝隙。

## 验收优先级

缩略看：参考与成品的阅读入口、图组边界、最大照片和主次是否接近所选结构？遮住全部贴纸后，版式是否仍成立？
放大看：同样一句字是否被做得过粗/过大，气泡线是否过重，相纸边是否过厚？次级小字是否只补充语气而不隐藏必要信息？
最后再检查贴纸种类。结构或照片角色不对时，不继续靠添加图标修补。
