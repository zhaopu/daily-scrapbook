# 调用示例与边界情境

## 照片 + 几句话，直接做

```text
使用 $daily-scrapbook，把这 4 张照片做成一页手帐式 plog。
周末和朋友吃了面，后来去公园走走，还碰到一只猫。
自然的手写批注，文字不要太多。
```

逐张看图、选主图、四张全部保留，组织一页片段拼贴并成图；没有时刻就不打印时刻，没拍到朋友不能补画朋友。只在真有猫照片时将猫作为照片素材。标题可有一组花字，正文仍保持清楚的手写字，贴纸与内容相关。

## 指定主图

```text
使用 $daily-scrapbook，用这 4 张图做一页。
最后一张是我最喜欢的表情，放大；其余是做饭过程。
标题“今天我下厨”，不要日期。
```

末图作情绪主图，其他图补充过程。输入顺序不自动等同发生顺序。保留指定标题，不添日期。

## 只分析

```text
使用 $daily-scrapbook，先看看这几张照片怎么排，先别生图。
```

给主图选择、一个优先版式与短文案，不调用生成，不让用户填十个风格选项。

## 局部改稿

```text
使用 $daily-scrapbook，把这张手账里的“去了杭州”改成“出门走走”，其他别动。
```

只编辑指定文字，核查照片与排版没有无故变化，不重做整页。

## 只有两张却要四张不同场景

```text
使用 $daily-scrapbook，只有两张照片，但想要四张不同场景的一页。
```

不生成两个假场景充数；说明两图配局部细节可行，或补两张。坚持四个来源时等待补图。

## 原照片不允许重绘

```text
使用 $daily-scrapbook，四张图排一页，人物像素不要改变，要可编辑图层。
```

不能整页生成后宣称无损；用用户授权的原图图层排版方式，工具不支持则明确只完成方案。提示词“保持身份”不等于像素保证。

## 内容图与参考图混合

```text
使用 $daily-scrapbook，第一张仅参考风格，后四张是我的照片。
做一页周末记录，不要带入参考里的人。
```

记录 S1、P1—P4，实际工具顺序与提示词对应；参考照片、文字、人物不进新页。工具引用窗口不足先解决输入覆盖，不少传。

## 七张全部用

```text
使用 $daily-scrapbook，这 7 张全要，做成一组手账。
```

先告知“建议两页，第一页面向哪些照片、第二页面向哪些照片，以及为什么这样分”，例如4+3；用户已经要求一组而没有限定页数，告知后可继续分别生成检查。不能只选四张，不做两页并排的展示海报。若用户原本要求一页，则先给一页保留全图方案，并提出两页建议，不直接拆页。

## 图多但要求一页

```text
使用 $daily-scrapbook，这6张做一页，全部保留。想要人物抠图、花字、小贴纸，但不要拥挤。
```

六个来源全部编号并安排位置：主角抠图、场景照、小照片卡、物件贴纸可以混用。生成前说明本次是一页全六张，并可提出两页会更舒展的建议；本次仍按一页制作。没有获得用户减图指示时不能“精选”掉两张。
