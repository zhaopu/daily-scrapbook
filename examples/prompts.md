# 使用示例

使用这些提示时，同时附上自己的照片。版式编号与仓库白模一致。

## 1. 入门：交给 AI 推荐

```text
使用 $daily-scrapbook，把这几张照片做成手帐式 plog。
大概内容：周末去公园，带了水果，坐着聊了很久。
照片全部保留，文字少一点，排版自由，配一些小贴纸。
如果建议多页，先说明页数、分配和理由。
```

## 2. A：一张主图承接情绪

```text
使用 $daily-scrapbook，用 A 情绪主图＋片段浮贴。
最后一张是我最喜欢的笑脸，作为大图，其他照片补充活动过程。
所有照片都要，花字和贴纸轻巧一点，避免太满。
```

## 3. B：日常碎片

```text
使用 $daily-scrapbook，用 B 日常碎片拼贴。
这些是今天的早餐、路边花、咖啡和晚饭。
不用编几点几分，保留随手记录的感觉。
```

## 4. C：周末小报

```text
使用 $daily-scrapbook，用 C 周末小报。
周末逛了书店，之后和朋友吃饭。
分成“逛逛书店”和“吃点好的”两组，全部照片保留。
图组内可以错位、叠放，别像整齐表格。
```

## 5. D：有先后顺序的时间轴

```text
使用 $daily-scrapbook，用 D 小型时间轴。
顺序是：准备材料、搅拌、烘烤、出炉、分给朋友。
没有记录具体时刻，就只写步骤，不写钟点。
```

## 6. E：围绕一个主题

```text
使用 $daily-scrapbook，用 E 主题中心＋周边细节。
今天给猫搭了一个新窝，这几张是搭建过程和它进去后的样子。
以猫为主角，配局部细节，别增加照片里没有的动作。
```

## 7. F：人物抠图与成长记录

```text
使用 $daily-scrapbook，用 F 主角抠图＋照片卡。
宝宝入托第一天，妈妈陪着，慢慢开始走向独立。
人物和书包可以做描边抠图，花字、小贴纸丰富一点。
全部照片保留，不能自行删；一页太挤就先给拆页建议。
```

## 8. 先比较两个方向

```text
使用 $daily-scrapbook，先不生图。
看看这组照片适合 F 主角抠图还是 C 小报，给我两个简短方案。
说明主图、文案与照片分配。
```

## 9. 只改局部

```text
使用 $daily-scrapbook，把这张成图里的“难忘的一天”改成“周末碎片”。
只修改这段文字，其他照片、人物和排版尽量保留。
```

## 10. 保留原图像素的特殊要求

```text
使用 $daily-scrapbook，用原照片图层排版，不要生成式重绘人脸。
照片全部保留，给可编辑图层；工具不支持时先说明能交付什么。
```

这项要求与默认的生成式成图不同，是否能完成取决于宿主提供的原图合成与图层工具。不能仅靠提示词承诺像素无损。
